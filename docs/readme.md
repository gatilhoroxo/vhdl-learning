# Aprendendo sobre VHDL

## Objetivos principais

- **Ler VHDL**: entender a descrição escrita pelo desenvolvedor.
- **Entender o hardware**: identificar o circuito que a descrição representa.
- **Verificar a implementação**: investigar se o comportamento simulado e o circuito implementado atendem aos requisitos, incluindo as restrições de temporização.

# Analisando códigos existentes

## Investigação ativa

1. Qual é a responsabilidade desse módulo?
2. Quais são suas entradas e saídas?
3. Quais sinais são internos?
4. Quais partes descrevem lógica combinacional e quais descrevem lógica sequencial?
5. Como esse módulo se conecta aos demais?
6. Como posso verificar se ele funciona como esperado?
